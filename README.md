# 🐌 最強蝸牛公會數據統計與圖片辨識管理系統

專為《最強蝸牛》公會長打造的每週數據統整與圖片智能辨識工具。支援遊戲截圖、Excel 截圖自動 OCR 提取，自動計算「防、攻、選、總、均」，並支援 Excel 匯出入與 Line/Discord 週報一鍵生成。

---

## 🚀 快速啟動方法

在 Windows 系統中，有兩種啟動方式：

### 方式一：一鍵批次啟動 (推薦)
1. 在資料夾中直接**滑鼠雙擊 `start.bat`**。
2. 系統會自動啟動本地服務並在預設瀏覽器中開啟 `http://localhost:8000`。

### 方式二：命令列啟動
開啟 PowerShell 或 CMD，執行：
```bash
python server.py
```

## 📸 圖片辨識使用說明

依您的要求，**初始狀態名單保持空白**，您可以親自驗證圖片辨識功能：

### 支援兩種主要截圖情境：
1. **底欄固定欄位截圖**（如公會長最新提供的 5392 / 235M 橫條截圖）：
   - 自動定位並提取：
     - 領導力：`5392`
     - 血量：`235M` ➜ **`235,000(K)`**
     - 攻擊：`56.1M` ➜ **`56,100(K)`**
     - 防禦：`36.8M` ➜ **`36,800(K)`**
     - 追擊：`41.8M` ➜ **`41,800(K)`**
2. **公會戰兵種上陣全螢幕截圖**（如「Europa」、「命不語」）：
   - 自動定位上方玩家名稱（如 `Europa`、`命不語`）。
   - 自動定位下方進度條領導力（如 `3751`、`3402`）。
   - 自動擷取四圍屬性數值並自動轉換 `M` 為 `(K)` 單位。

### 陸續存取與同名覆蓋工作流：
- **上傳多少，存取多少**：上傳 1 張圖，校對清單就精準呈現該張圖的 1 筆數據！
- **同名自動覆蓋**：若名冊中已存在同名成員，以最新上傳之數據直接覆蓋更新，不重複佔位！
- **批次多選**：支援一次框選多張成員截圖拖曳上傳，系統逐張處理並列入校對清單！

## 🧮 包含的 11 個關鍵欄位與公式

1. **遊戲暱稱**：成員遊戲 ID
2. **領導力**：基礎面板數值
3. **血量(K)**：萬/千單位血量
4. **攻擊(K)**：萬/千單位攻擊力
5. **防禦(K)**：萬/千單位防禦力
6. **追擊(K)**：萬/千單位追擊力
7. **防**：預設公式 `血量(K) / 15 + 防禦(K)`
8. **攻**：預設公式 `攻擊(K) * 1.5 + 追擊(K)`
9. **選**：公會選拔加權指標（可於公式設定調整）
10. **總**：`攻 + 防`
11. **均**：`總 / 領導力`（保留一位小數）

> 💡 **公式調整**：點擊頂部 **「⚙️ 公式設定」**，即可直接調整除數、倍率與小數位數，全表格即時重新計算。後續您提供細部公式內容時，我們會進一步精準更新！

## 🛠️ 其他強大功能

- **週次管理**：點擊 `+ 新週` 或 `複製名單`，每週數據分頁獨立保存。
- **即時編輯**：在主表格中直接點擊任何數字即可就地修改。
- **欄位排序**：點擊表頭任意欄位（如「均」、「總」）即可切換由高到低降冪或升冪排序。
- **匯出 Excel**：一鍵輸出格式完整的 `.xlsx` 活頁簿。
- **複製週報**：一鍵產生適合發布在 Line / Discord 群組的榮譽榜與數據公告。
